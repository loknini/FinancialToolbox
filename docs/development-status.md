## 配置和边界

本地存储与导出默认可用。OCR 和聊天模型默认 disabled，配置供应商和服务端凭证后重启 API/Worker。模型须支持标准非思考模式的 Chat Completions 工具调用；协议模拟通过不等于供应商已接入。票种均为 adapter_only，尚无真实样本准确率验证。

导出访问期限默认 7 天，可配置；分享不超过文件期限和用户确认的绝对期限。访问过期与物理删除不同，原件/导出/审计统一清理、retained 聊天的生产保留期限、注销和微信订阅消息仍待策略及实现。临时聊天清理依赖 Worker 运行。

生产校验要求 PostgreSQL、COS、关闭开发登录，模型 HTTP 配置需 HTTPS。尚未用真实微信、COS/OCR、模型、PostgreSQL 或真机完成验证；上线还需要用户级限流、业务语义评测和部署检查。
