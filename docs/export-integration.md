# 导出与分享对接指南（0.3.0）

导出和分享已实现，默认本地环境即可联调。实际字段见 [OpenAPI](openapi.json)，完整约定见 [接口契约](api-contract.md)。真实 COS、PostgreSQL 并发及微信真机仍需独立验证。

## 一、导出流程

1. POST /api/v1/exports，携带 Bearer 和 Idempotency-Key，选择 format=excel/pdf、source_type=invoices/tax_calculations。
2. selection 只选一种：ids（本人非空、不重复 ID 数组）、batch（仅票据，需本人 batch_id）、filter（允许的创建日期或票面筛选）。所有显式 ID 必须归属本人，不能悄悄忽略外部 ID。
3. 票据 review_scope 默认 confirmed；明确选择 all 才包含待核对记录。拆税不传 review_scope，不能按销售方或票面日期筛选。
4. group_by 为 none/seller/month；票据按票面日期分月，日期不明单列；拆税按北京时间的创建月份分组。销售方分组仅适用于票据。
5. 创建响应 202 返回 queued、记录数和快照时间。当前在创建事务中完成快照；没有数据返回 EMPTY_EXPORT（422），不创建空导出。
6. Worker 读取快照生成文件，查询 /exports/{id} 得到 queued/processing/succeeded/failed/cancelling/cancelled。succeeded 时 file 可用，再 GET /exports/{id}/download-url。
7. 下载按返回的 filename、content_type 保存或打开。PDF 是汇总报告，与原始发票不同；Excel 是汇总及明细工作簿。
8. 未完成任务可 POST /exports/{id}/cancel {}。离开页面不取消；取消后不发布该任务的最终文件。失败任务当前不提供 retry 接口，可使用新的幂等键创建新快照任务。

所有创建重试复用原幂等键；改范围或格式属于新操作，使用新键。列表支持 format/status/date_from/to/cursor/limit；创建日期为北京时间自然日，游标绑定用户与筛选。/records 和 /users/me/tools 已包含导出。

票据在后台仍识别时可以明确导出已有结果；前端显示“仅包含快照时已识别的数据”。快照保留创建时的字段和版本，后续修正、确认或新识别结果不会改变该次导出。

## 二、文件内容和金额

票据 Excel 包含汇总、票据明细、商品明细、待核对项目；拆税 Excel 包含汇总和计算记录。没有待核对记录时相应页保留表头。表头冻结、列宽和换行设置，待核对行用浅黄色标识。超过 Excel 单表行数时另建续表，不丢行。

常规金额是数值单元格，税率是百分比数值，数量和单价为精确度允许的数值，日期为可排序的日期值；创建时间按北京时间展示。号码、代码、税号和资源 ID 保留文本及前导零。文本开头的公式符号做防护，不输出可执行的用户公式。

Excel 对超过 15 位有效数字的金额等数据使用精确文本和文本格式，避免大金额被 Excel 舍入。数值零保留，未知值留空，不填零。超长文本仍在单元格中完整保留，但 Excel 单行可显示高度有自身限制，必要时通过公式栏查看全文。

汇总使用 Decimal，按分组及币种隔离。每个金额列是已知部分的合计，同时给出缺失数；全缺失时不填 0。UNKNOWN 币种不合计，不进行汇率换算。待核对记录即使被显式纳入，也不能在报告中伪装为已确认。

PDF 包含快照时间、记录数、待核对数、分组金额和记录摘要；中文长文本会换行及跨页，表头重复、页码和报告说明保留。完整商品明细适合使用 Excel。

## 三、主动分享

1. 仅文件可用时，用户主动 POST /exports/{id}/share {"expires_in_days":7}，提供幂等键。允许 1 至 30 天，默认 7；实际到期不超过导出文件到期时间。
2. 首次响应 201 包含 token、share_path、expires_at。前端保存该次结果，使用 share_path 进入小程序分享页。
3. GET /exports/{id}/share 仅返回状态和到期时间，不返回 token。每个导出最多一个活动分享；另一个新操作尝试创建时返回 SHARE_ALREADY_EXISTS（409）。
4. 原创建键在 24 小时响应保留期内可幂等恢复同一 token；查询状态是当前状态来源。凭证在分享表中存哈希，幂等缓存中的凭证使用认证加密，不保存明文。
5. 分享页无需登录即可 GET /shares/{token}。仅有文件名、格式、大小、分享到期时间和说明，不含用户身份、来源票据接口地址或原件链接。
6. GET /shares/{token}/download-url 签发短期下载地址；时长不超过配置、分享剩余时长和文件剩余时长。该 URL 只对应本次导出文件。
7. DELETE /exports/{id}/share 撤销当前分享，可重复。无效或撤销返回 SHARE_UNAVAILABLE（404），自然到期返回 SHARE_EXPIRED（410）。撤销后可创建新的分享，新凭证不同。

当前本地下载会在读取文件时再检查分享撤销及过期，已签发地址也会被拒绝。COS 已发出的短期签名 URL 在自身有效期内可能仍可访问；撤销后不再签发新地址，不承诺回收已下载文件。

signing key 轮换后，旧分享的加密创建响应可能无法恢复并返回 SHARE_REPLAY_UNAVAILABLE（409）；活动分享状态仍可查询，可以撤销后创建新分享。分享创建目前只开放显式 HTTP 操作；Agent 分享工具会与下一阶段的持久化确认 action 一起接入。

## 四、配置与保留

```dotenv
FT_EXPORT_RETENTION_DAYS=7
# 可选：可读且有授权的中文 TrueType 字体
# FT_PDF_FONT_PATH=/path/to/chinese-font.ttf
```

导出访问期限从文件成功生成时开始，默认 7 天为当前可配置实现值，不是已完成的生产数据保留政策。API、Worker 使用相同配置。到期后 file.status=expired，普通下载和分享不再获得授权。

默认 PDF 使用标准中文 CID 字体 STSong-Light，已用本机 PDF 渲染验证。若需嵌入字体，配置有授权的中文 TTF；需在目标微信查看器验证。不要把 Windows 字体未经授权复制到服务器发布。

访问过期与物理删除不同：当前不自动删除原始记录、快照或文件。COS 建议为 exports/ 前缀配置与访问期限一致、留有时间余量的生命周期，处理旧文件和未完成发布的遗留对象。已开始生成但取消/过期 Worker 的私有对象可能遗留，没有下载授权；统一物理清理策略仍在上线准备阶段处理。

当前快照在创建事务内读取、分批落库，Excel 流式写入；PDF 的完整排版和分组仍使用内存。大量记录的事务时长、峰值内存、COS 生成文件及真机大文件下载需要实际压测；本轮未宣称完成大规模性能验证。
